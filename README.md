# Тестовое задание: Бронирование билетов в кинотеатр

Одностраничное приложение (SPA) для выбора даты, сеанса и бронирования мест в кинозале. 
Данные сохраняются в `localStorage` и не теряются при перезагрузке страницы.

## Запуск проекта

Для корректной работы запустите локальный сервер:
1. Если используете **VS Code**, установите расширение **Live Server**, нажмите правой кнопкой мыши на `index.html` и выберите **"Open with Live Server"**.
2. Либо через терминал (если установлен Python): 
   `python -m http.server`
   И откройте `http://localhost:8000` в браузере.

## Технологии и ограничения
* **HTML5 / CSS3**
* **Vanilla JavaScript (ES5)** — код написан без использования `let`, `const`, стрелочных функций и других возможностей ES6, чтобы обеспечить полную кроссбраузерность и поддержку **IE 10** (как указано в ТЗ).
* **LocalStorage** — используется для хранения состояния броней.
* Никаких сторонних библиотек (jQuery, React и т.д.) не подключено, только чистый JS.

## Реализованный функционал

* **Работа с датами:** 
  * Отображается 15 дней: 1 неделя до текущей даты (архив) и 1 неделя после (для бронирования).
  * Глубина архива и период бронирования соответствуют требованиям ТЗ.
* **Сеансы:** 
  * 6 сеансов в день (с 10:00 до 20:00 с шагом 2 часа (по ТЗ)).
  * Сеансы, время которых уже прошло, помечаются как «архивные» (серые) и доступны только для просмотра.
* **Схема зала:**
  * Зал рассчитан на 80 мест: 8 рядов (от A до H) по 10 мест.
  * Нумерация мест: ряд + номер (например, `A1`, `B10`).
  * Свободные места (зеленые) — можно бронировать и отменять бронь.
  * Занятые места (красные) — клик по ним отменяет бронь.
  * В архивных сеансах все места становятся неактивными (серыми), изменить данные нельзя.
* **Хранение данных:**
  * Брони сохраняются в `localStorage` под ключом `cinema_bookings_v1`.
  * Структура данных: 
    ```json
    {
      "2026-11-08": {
        "18:00": ["B7", "B8"]
      }
    }
